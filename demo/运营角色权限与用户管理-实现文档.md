# 运营角色权限显隐 + 系统用户管理 —— 业务实现文档

> 本文档面向「在另一个同类 AI 招聘系统项目中复现本功能」的 AI / 开发者。
> 仅记录**业务功能代码实现**，**不含**大模型 API Key / base-url / 模型名、Embedding/Rerank 配置、PostgreSQL/Redis/RabbitMQ 连接、`app.mock.enabled` 等任何**本地基础设施配置**——这些由各项目自身的本地配置文件承载，请按你自己的环境填写。

## 1. 背景与目标

- 系统有两类业务角色：**HR（招聘负责人）**、**OPS（运营人员）**，另有一个 **ADMIN**。
- 当前问题：前端未按角色做菜单/路由显隐，**运营人员(OPS)登录后仍可见** `智能匹配 / 面试管理 / AI 面试官` 等仅属 HR 的功能；且系统缺少**用户管理**界面来维护系统用户与角色。
- 目标：
  1. **前端按角色显隐**：OPS 不可见 `智能匹配(/matches)`、`面试管理(/interviews)`、`AI面试官(/interview-agent)`；新增 `用户管理(/users)` 仅 OPS 可见。
  2. **修正认证 store**：登录返回的是 `user.roles`（复数数组），原先前端误读单数 `user.role` 字段导致角色恒空，需修正。
  3. **用户管理 UI**：新增用户管理页（表格 + 新建/编辑弹窗 + 角色多选 + 启停 + 删除），对接后端 `/api/admin/users` API。
  4. **后端业务补全**：用户列表返回每用户 `roles`；新增角色主数据端点 `GET /api/admin/users/roles`；创建用户支持请求体 `roles` 指定初始角色。

### 角色与种子账号
| 用户名 | 密码 | 角色 |
|--------|------|------|
| `hr_user` | `123456` | HR |

## 3. 后端实现（Spring Boot 3 + Sa-Token + MyBatis-Plus）

### 3.1 登录返回 `roles`（前置依赖）
前端显隐全部依赖登录返回的 `user.roles` 数组。登录服务在拼装用户信息时把用户的角色码数组放进 `roles` 字段（`sys_user_role` → `sys_role.code`）。

```java
// AuthService#login 关键返回结构
StpUtil.login(user.getId());                       // Sa-Token 登录
Map<String, Object> result = new LinkedHashMap<>();
result.put("token", StpUtil.getTokenValue());
Map<String, Object> userInfo = new LinkedHashMap<>();
userInfo.put("id", user.getId());
userInfo.put("username", user.getUsername());
userInfo.put("realName", user.getRealName());
userInfo.put("department", user.getDepartment());
userInfo.put("roles", rolesOf(user.getId()));      // ← List<String>，如 ["HR"]
result.put("user", userInfo);
return result;
```

`rolesOf(userId)`：查 `sys_user_role` 得 roleIds → 查 `sys_role` 得 code 列表。
登录还需校验：账号不存在 / 密码不匹配(BCrypt) / `status="disabled"` 时拒绝登录。

> ⚠️ 关键：登录返回的 `user.roles` 必须是**数组**。前端一切显隐都基于它。

### 3.2 路由级 RBAC（Sa-Token 拦截器）
在 `WebMvcConfigurer` 中配置 Sa-Token 拦截器，按「方法 + 路径」粒度校验角色。**后端是权威鉴权边界**，前端显隐仅为用户体验层。

```java
@Configuration
public class SaTokenConfig implements WebMvcConfigurer {
    private final AppProperties appProperties;
    public SaTokenConfig(AppProperties appProperties) { this.appProperties = appProperties; }

    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        boolean mock = appProperties.useMock();   // 本地基础设施开关，不在本文档范围
        registry.addInterceptor(new SaInterceptor(handle -> {
            if (mock) return;                      // mock 模式放开，便于无依赖演示

            // 全局登录校验（排除登录、健康检查）
            SaRouter.match("/api/**")
                    .notMatch("/api/auth/login")
                    .notMatch("/api/health/**")
                    .notMatch("/actuator/**")
                    .check(r -> StpUtil.checkLogin());

            // ★ 用户管理 - 仅 OPS
            SaRouter.match("/api/admin/**", r -> StpUtil.checkRole("OPS"));

            // 岗位写操作 - 仅 OPS
            SaRouter.match("/api/jobs",     r -> { if ("POST".equalsIgnoreCase(method())) StpUtil.checkRole("OPS"); });
            SaRouter.match("/api/jobs/*",   r -> { String m = method(); if ("PUT".equalsIgnoreCase(m) || "DELETE".equalsIgnoreCase(m)) StpUtil.checkRole("OPS"); });

            // 简历删除 - 仅 OPS
            SaRouter.match("/api/resumes/*", r -> { if ("DELETE".equalsIgnoreCase(method())) StpUtil.checkRole("OPS"); });

            // 候选人匹配：执行/反馈 仅 HR
            SaRouter.match("/api/matches/job/*/run",     r -> { if ("POST".equalsIgnoreCase(method())) StpUtil.checkRole("HR"); });
            SaRouter.match("/api/matches/*/feedback",    r -> { if ("POST".equalsIgnoreCase(method())) StpUtil.checkRole("HR"); });

            // 面试题生成/采纳、AI 面试、HITL 确认、离线评估 - 仅 HR
            SaRouter.match("/api/interviews/*/questions/generate",   r -> { if ("POST".equalsIgnoreCase(method())) StpUtil.checkRole("HR"); });
            SaRouter.match("/api/interviews/*/questions/*/adopt",    r -> { if ("PUT".equalsIgnoreCase(method()))  StpUtil.checkRole("HR"); });
            SaRouter.match("/api/interview-agent/interviews/*/start", r -> { if ("POST".equalsIgnoreCase(method())) StpUtil.checkRole("HR"); });
            // ... 其余 HR 专属端点同理省略
        })).addPathPatterns("/api/**");
    }
    private static String method() { return SaHolder.getRequest().getMethod(); }
}
```

### 3.3 用户管理 Controller（`/api/admin/users`）
类级 `@SaCheckRole("OPS")` 兜底 + 路由级 `/api/admin/**`→OPS 双重鉴权。

```java
@RestController
@RequestMapping("/api/admin/users")
@SaCheckRole("OPS")
public class UserAdminController {
    private final UserService userService;
    public UserAdminController(UserService userService) { this.userService = userService; }

    /** GET —— 用户列表（带 roles，password 不输出） */
    @GetMapping
    public List<Map<String, Object>> list() {
        List<Map<String, Object>> result = new ArrayList<>();
        for (SysUser u : userService.listAll()) {
            Map<String, Object> row = new LinkedHashMap<>();
            row.put("id", u.getId());
            row.put("username", u.getUsername());
            row.put("realName", u.getRealName());
            row.put("email", u.getEmail());
            row.put("phone", u.getPhone());
            row.put("department", u.getDepartment());
            row.put("status", u.getStatus());
            row.put("createdAt", u.getCreatedAt());
            row.put("roles", userService.roleCodesOf(u.getId()));   // ← 角色码数组
            result.add(row);                                       // 注意：不 put password
        }
        return result;
    }

    /** GET /roles —— 角色主数据（供前端角色多选下拉） */
    @GetMapping("/roles")
    public List<SysRole> roles() { return userService.listRoles(); }

    /** POST —— 创建用户（BCrypt 加密；可传 roles 指定初始角色，不传默认 HR） */
    @PostMapping
    public ResponseEntity<Map<String, Object>> create(@RequestBody Map<String, Object> body) {
        SysUser user = new SysUser();
        user.setUsername(asString(body.get("username")));
        String password = asString(body.get("password"));
        user.setRealName(asString(body.get("realName")));
        user.setEmail(asString(body.get("email")));
        user.setPhone(asString(body.get("phone")));
        user.setDepartment(asString(body.get("department")));
        user.setStatus(asString(body.get("status")));
        SysUser created = userService.create(user, password);
        Map<String, Object> resp = new LinkedHashMap<>();
        if (created == null) {
            resp.put("success", false);
            resp.put("message", "创建失败 (用户名可能已存在)");
            return ResponseEntity.badRequest().body(resp);
        }
        List<String> roleCodes = toStringList(body.get("roles"));
        if (!roleCodes.isEmpty()) userService.assignRoles(created.getId(), roleCodes); // 覆盖默认 HR
        resp.put("success", true);
        resp.put("id", created.getId());
        resp.put("roles", roleCodes.isEmpty() ? List.of("HR") : roleCodes);
        return ResponseEntity.ok(resp);
    }

    /** PUT /{id} —— 更新用户（含改密/启停；空密码保留原值） */
    @PutMapping("/{id}")
    public ResponseEntity<Map<String, Object>> update(@PathVariable Long id, @RequestBody SysUser body) {
        body.setId(id);
        boolean ok = userService.update(body);
        return ResponseEntity.ok(Map.of("id", id, "updated", ok));
    }

    /** DELETE /{id} —— 删除用户 */
    @DeleteMapping("/{id}")
    public ResponseEntity<Map<String, Object>> delete(@PathVariable Long id) {
        return ResponseEntity.ok(Map.of("id", id, "deleted", userService.delete(id)));
    }

    /** PUT /{id}/roles —— 分配角色 body {roles:["HR","OPS"]}（先清后建） */
    @PutMapping("/{id}/roles")
    public ResponseEntity<Map<String, Object>> assignRoles(@PathVariable Long id, @RequestBody Map<String, Object> body) {
        List<String> roleCodes = toStringList(body.get("roles"));
        userService.assignRoles(id, roleCodes);
        return ResponseEntity.ok(Map.of("id", id, "assigned", true, "roles", roleCodes));
    }

    private static String asString(Object o) { return o == null ? null : String.valueOf(o); }
    @SuppressWarnings("unchecked")
    private static List<String> toStringList(Object o) {
        if (o instanceof List<?> list) {
            List<String> codes = new ArrayList<>();
            for (Object item : list) if (item != null) codes.add(String.valueOf(item));
            return codes;
        }
        return List.of();
    }
}
```

### 3.4 用户管理 Service
密码统一 `BCryptPasswordEncoder`；新建用户**默认关联 HR 角色**；分配角色采用「先清空原关联，再按 roleCodes 重建」。

```java
@Service
public class UserService {
    private static final Logger log = LoggerFactory.getLogger(UserService.class);
    private final SysUserMapper userMapper;
    private final SysUserRoleMapper userRoleMapper;
    private final SysRoleMapper roleMapper;
    private final BCryptPasswordEncoder passwordEncoder = new BCryptPasswordEncoder();
    /* 构造器注入三个 Mapper */

    /** 新建用户：rawPassword 明文 BCrypt 加密；默认关联 HR 角色 */
    public SysUser create(SysUser user, String rawPassword) {
        if (user == null) return null;
        try {
            if (user.getStatus() == null || user.getStatus().isBlank()) user.setStatus("active");
            if (user.getCreatedAt() == null) user.setCreatedAt(LocalDateTime.now());
            String pwd = rawPassword == null || rawPassword.isBlank() ? "123456" : rawPassword;
            user.setPassword(passwordEncoder.encode(pwd));
            userMapper.insert(user);
            Long hrRoleId = findRoleIdByCode("HR");
            if (hrRoleId != null) userRoleMapper.insertOne(user.getId(), hrRoleId); // 默认 HR
            return user;
        } catch (Exception e) { log.warn("create user failed: {}", e.getMessage()); return null; }
    }

    /** 更新：空密码保留原值；明文(不以 $2 开头)才加密 */
    public boolean update(SysUser user) {
        if (user == null || user.getId() == null) return false;
        try {
            if (user.getPassword() == null || user.getPassword().isBlank()) {
                SysUser existing = userMapper.selectById(user.getId());
                if (existing != null) user.setPassword(existing.getPassword());
            } else if (!user.getPassword().startsWith("$2")) {
                user.setPassword(passwordEncoder.encode(user.getPassword()));
            }
            return userMapper.update(user) > 0;
        } catch (Exception e) { return false; }
    }

    /** 删除：同时清理 sys_user_role 关联 */
    public boolean delete(Long id) {
        if (id == null) return false;
        try {
            userRoleMapper.delete(new LambdaQueryWrapper<SysUserRole>().eq(SysUserRole::getUserId, id));
            return userMapper.deleteById(id) > 0;
        } catch (Exception e) { return false; }
    }

    public List<SysUser> listAll() { return userMapper.selectAll(); }

    /** 用户的角色 code 列表（列表展示/编辑回显用） */
    public List<String> roleCodesOf(Long userId) {
        if (userId == null) return List.of();
        try {
            List<SysUserRole> userRoles = userRoleMapper.selectList(
                    new LambdaQueryWrapper<SysUserRole>().eq(SysUserRole::getUserId, userId));
            if (userRoles.isEmpty()) return List.of();
            List<Long> roleIds = userRoles.stream().map(SysUserRole::getRoleId).collect(Collectors.toList());
            return roleMapper.selectList(new LambdaQueryWrapper<SysRole>().in(SysRole::getId, roleIds))
                    .stream().map(SysRole::getCode).collect(Collectors.toList());
        } catch (Exception e) { return List.of(); }
    }

    public List<SysRole> listRoles() { return roleMapper.selectAll(); }

    /** 重置角色：先删旧关联，再按 roleCodes 重建；roleCodes 为空则仅清空 */
    public boolean assignRoles(Long userId, List<String> roleCodes) {
        if (userId == null) return false;
        try {
            userRoleMapper.delete(new LambdaQueryWrapper<SysUserRole>().eq(SysUserRole::getUserId, userId));
            if (roleCodes == null || roleCodes.isEmpty()) return true;
            List<SysUserRole> toInsert = new ArrayList<>();
            for (String code : roleCodes) {
                Long roleId = findRoleIdByCode(code);
                if (roleId != null) { SysUserRole rel = new SysUserRole(); rel.setUserId(userId); rel.setRoleId(roleId); toInsert.add(rel); }
            }
            if (!toInsert.isEmpty()) userRoleMapper.insertBatch(toInsert);
            return true;
        } catch (Exception e) { return false; }
    }

    private Long findRoleIdByCode(String code) { /* 在 sys_role 中按 code 忽略大小写匹配 id */ }
    public BCryptPasswordEncoder passwordEncoder() { return passwordEncoder; }
}
```

```java
@Mapper public interface SysUserRoleMapper extends BaseMapper<SysUserRole> {
```

## 4. 前端实现（Vue 3 + Vite + Pinia + Ant Design Vue）

### 4.1 认证 store（由 `user.roles` 数组派生）
> 修正重点：登录返回的是 `user.roles`（**复数数组**），不要读 `user.role`。

```js
// store/auth.js —— Pinia Composition API
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useAuthStore = defineStore('auth', () => {
  const token = ref(localStorage.getItem('token') || '')
  const user = ref(JSON.parse(localStorage.getItem('user') || 'null'))

  const isAuthenticated = computed(() => !!token.value)
  // ★ 后端登录返回 user.roles 数组，如 ["HR"] / ["OPS"]
  const roles = computed(() => user.value?.roles || [])
  const role = computed(() => roles.value[0] || '')             // 主角色，用于标签
  const username = computed(() => user.value?.username || user.value?.name || '')

  // 是否拥有指定角色之一；不传参视为不限制（用于路由/菜单显隐）
  function hasAnyRole(...codes) {
    if (!codes || codes.length === 0) return true
    return codes.some((c) => roles.value.includes(c))
  }

  function login(tokenValue, userInfo) {
    token.value = tokenValue; user.value = userInfo
    localStorage.setItem('token', tokenValue)
    localStorage.setItem('user', JSON.stringify(userInfo))
  }
  function logout() {
    token.value = ''; user.value = null
    localStorage.removeItem('token'); localStorage.removeItem('user')
  }
  return { token, user, isAuthenticated, roles, role, username, hasAnyRole, login, logout }
})
```

```js
  // ★ 仅 OPS 可见（新增）
  { path: '/users', component: () => import('@/views/UsersView.vue'), meta: { requiresAuth: true, roles: ['OPS'], title: '用户管理' } },
  { path: '/:pathMatch(.*)*', redirect: '/' }
]

router.beforeEach((to, from, next) => {
  const authStore = useAuthStore()
  if (to.meta.requiresAuth && !authStore.isAuthenticated) return next('/login')
  if (to.path === '/login' && authStore.isAuthenticated) return next('/')
  // ★ 角色级守卫：声明了 meta.roles 且无交集 → 回首页
  if (to.meta.roles && to.meta.roles.length && !authStore.hasAnyRole(...to.meta.roles)) return next('/')
  next()
})
```

### 4.3 顶部菜单按角色过滤（`components/MainLayout.vue`）
用一个「路径 → 允许角色」映射过滤 `navItems`。

```js
const navItems = [
  { path: '/', label: '仪表盘', icon: '...' },
  { path: '/jobs', label: '岗位管理', icon: '...' },

const routeRoles = { '/matches': ['HR'], '/interviews': ['HR'], '/interview-agent': ['HR'], '/users': ['OPS'] }
const visibleNavItems = computed(() => navItems.filter((i) => {
  const need = routeRoles[i.path]
  return !need || need.some((r) => authStore.roles.includes(r))
}))

// 角色标签（顶部下拉）
const roleMap = { HR: '招聘负责人', OPS: '运营人员', ADMIN: '管理员' }
```

模板中导航 `v-for="item in visibleNavItems"`（注意：原来是 `navItems`，要改成 `visibleNavItems`）。
菜单显隐规则：仪表盘/岗位/简历/Agent对话 对全部角色可见；智能匹配/面试管理/AI面试官 仅 HR；用户管理 仅 OPS。

### 4.4 用户管理 API 函数（`api/index.js` 追加）
axios 实例 `baseURL: '/api'`，登录后请求头注入 `satoken`；响应拦截兼容 `{code,msg,data}` 信封与直接返回两种，401 注销跳 `/login`。

```js
// ===== 用户管理（/api/admin/users，OPS 专属） =====
export function adminUserList()           { return request.get('/admin/users') }
export function adminRoles()              { return request.get('/admin/users/roles') }
export function adminUserCreate(payload)  { return request.post('/admin/users', payload) }   // {username,password,...,roles}
export function adminUserUpdate(id, payload) { return request.put(`/admin/users/${id}`, payload) } // 含改密/启停
export function adminUserDelete(id)       { return request.delete(`/admin/users/${id}`) }
export function adminUserAssignRoles(id, roles) { return request.put(`/admin/users/${id}/roles`, { roles }) }
```

### 4.5 用户管理页面（`views/UsersView.vue` —— 新增文件）
功能要点（伪代码 + 关键逻辑；完整模板见下方实现清单）：

- `onMounted`：并发 `adminUserList() + adminRoles()`；`roleOptions = roles.map(r => ({label:`${r.name}（${r.code}）`, value:r.code}))`。
- 表格列：username / realName / department / email / phone / **roles（角色标签）** / **status（状态标签）** / createdAt / 操作(编辑·启停·删除)。
- 新建/编辑共用 `a-modal`：
  - 用户名（编辑时禁改）+ `a-input-password` 密码（编辑「留空不改」/可重置）+ 姓名/部门/邮箱/手机 + **角色 `a-select mode="multiple"`** + 状态(active|disabled)。
  - 保存：
    - 编辑 → `adminUserUpdate(id, {基本字段, password: null})` + `adminUserAssignRoles(id, roles)`；
    - 新建 → `adminUserCreate({含 roles})`。
- 启停 → `adminUserUpdate(id, { status })`；删除 → `adminUserDelete(id)`。
- **自我保护**：对 `u.id === authStore.user.id`（当前登录用户自身）禁止禁用/删除。

关键运行时逻辑片段：
```js
async function handleSave() {
  if (!editing.value && !form.value.username.trim()) { message.warning('请填写用户名'); return }
  saving.value = true
  try {
    if (editing.value) {
      const id = editing.value.id
      await adminUserUpdate(id, { realName, email, phone, department, status, password: form.value.password || null })
      await adminUserAssignRoles(id, form.value.roles)
    } else {
      await adminUserCreate({ username, password, realName, email, phone, department, status, roles: form.value.roles })
    }
    showForm.value = false; await load()
  } finally { saving.value = false }
}
function isSelf(u) { return String(u.id) === String(authStore.user?.id) }   // 自我保护
```
